# 태양광·풍력 입력 데이터

최적화 실행 파일은 이 폴더의 아래 두 원자료를 읽는다. 두 파일 모두 저장소에 포함되어 있으므로 기본 실행에 별도 다운로드는 필요하지 않다. 변환 코드는 [`green_ammonia/renewables.py`](../../green_ammonia/renewables.py)에 있다.

## PVGIS 태양광

`pvgis_35.5_-0.5_2013_v52.json`

- 출처: [PVGIS 시간별 발전량 API](https://re.jrc.ec.europa.eu/api/v5_2/seriescalc)
- 좌표: 위도 35.5°, 경도 −0.5°
- 연도: 2013
- PV 설비: 1 kWp, 결정질 실리콘, 고정식, 최적 경사각
- 시스템 손실: 14%
- 방사자료: PVGIS-SARAH2
- 표본: 시간별 발전출력 `P` 8,760개
- 모델 입력: 정격 1 kWp 설비의 `P`(W)를 1,000으로 나눈 MW/MWp 용량계수
- 연간 수율: 1,610.20651 kWh/kWp

PVGIS의 `P`에는 요청한 시스템 손실 14%가 이미 반영되어 있다. 실행 설정의 `solar_delivery_factor=1.0`은 이 출력에 손실을 다시 곱하지 않도록 한다.

## NEWA 풍력

`newa_35.5_-0.5_2013.nc`

- 출처: [NEWA 풍속 시계열 API](https://wps.neweuropeanwindatlas.eu/api/mesoscale-ts/v1/get-data-point)
- 요청 좌표: 위도 35.5°, 경도 −0.5°
- 실제 격자점: 위도 35.491188°, 경도 −0.512970°
- 연도·변수: 2013년 30분 간격 `WS10`
- 표본: 풍속 17,520개를 2개씩 묶어 8,760시간으로 변환
- 시간 변환: 연속된 두 풍속의 산술평균
- 높이 변환: `WS100 = WS10 × 10^0.143`
- 출력곡선: 절입 3 m/s, 정격 13 m/s, 차단 25 m/s
- 변환 후 평균 용량계수: 0.2195745624

위 평균 용량계수는 풍력단지 전달계수를 적용하기 전 값이다. 최적화의 시간별 전력수지에서는 `wind_delivery_factor=0.851`을 곱한다.
